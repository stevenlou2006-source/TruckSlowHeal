# Truck Slow Heal

在卡车内自动缓慢回血 —— 以最大生命值的 5% 为固定速率，让你在安全的卡车里慢慢恢复状态。

版本：0.1.0

## ⚠️ 重要说明

- **测试版**：本模组目前仍处于测试阶段，功能可能随时调整。
- **仅单人环境测试**：目前仅在单人模式下进行过完整测试，**多人联机环境未经验证**。如果你在联机时遇到回血异常、同步问题或卡顿，请及时反馈。
- **独立判断**：即便理论上每位玩家独立计算，多人环境下是否会出现同步或表现差异，仍需实际测试确认。

## ✨ 功能

- **卡车内自动回血**：只要玩家处于卡车范围内，且当前血量未满，就会自动缓慢恢复。
- **动态速率**：每秒回血 = **最大生命值 × 5%**（例如：100 上限回 5 HP/秒，200 上限回 10 HP/秒），无需复杂配置，天然适配高血量角色。
- **独立判断**：每个玩家独立计算是否在卡车内，设计上不会影响其他队友的回血节奏。
- **日志开关**：默认关闭详细日志，可随时开启用于调试。

## ⚙️ 机制说明

| 项目 | 说明 |
|---|---|
| 回血速率 | 最大生命值 × 5% / 秒（固定，不可配置） |
| 生效范围 | 仅卡车内部（基于游戏原生 `RoomVolumeCheck.inTruck` 判断） |
| 触发条件 | 在卡车内 且 当前血量 < 最大生命值 |
| 与游戏同步 | 遵循游戏原生主机权威机制，血量变更自动同步给所有队友 |

## 📦 安装

1. 确保已安装 [BepInExPack](https://thunderstore.io/c/repo/p/BepInEx/BepInExPack/)。
2. 将 `TruckSlowHeal.dll` 放入 `BepInEx/plugins` 文件夹。
3. 启动游戏，模组会自动生成配置文件。

## 🔧 配置

配置文件位置：`BepInEx/config/cn_xc.TruckSlowHeal.cfg`

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `EnableLog` | `false` | 是否输出详细日志（状态和回血记录） |

## ❓ 常见问题

**Q：为什么我血满了不回血？**
A：血量已满时不会回血，这是设计逻辑，避免溢出。

**Q：和队友联机时，我的回血会影响他们吗？**
A：设计上不会。模组独立判断每个玩家的状态，只回复自己的血量。但多人环境尚未完整测试，如有异常请反馈。

**Q：每秒回 5% 是写死的吗？**
A：是的，这是经过平衡性考量的固定值，避免过强的恢复能力破坏游戏体验。
